# clip-machine

**קלט: הקלטה של שעה. פלט: חמישה קטעים אנכיים עם כתוביות, מוכנים להעלאה.**

לכל בעל עסק יש הקלטה כזאת. וובינר, הרצאה, זום עם לקוח, לייב. **היא יושבת
בדרייב ולא עושה כלום**, כי לשבת ולחתוך ממנה קטעים זה עבודה של חצי יום.

**מה צריך על המחשב:**

```
node --version
ffmpeg -version
```

Node 22 ומעלה, ו-ffmpeg. במק: `brew install ffmpeg`. זה הכל.

---

## שלב 1. תמליל עם זמנים

הכלי צריך לדעת **מה נאמר ומתי**. שלוש דרכים, לפי מה שיש לכם:

1. 🔴 **הכי קל, ורוב האנשים לא יודעים שזה שם:** הקלטת ענן של זום מייצרת
   קובץ תמלול בעצמה. מורידים אותו מ-Recordings ליד הווידאו.
2. סרטון שהעליתם ליוטיוב: הכתוביות האוטומטיות ניתנות להורדה מ-Studio.
3. אין כלום: `pip install faster-whisper`, ואז מריצים אותו על הקובץ.

בכל מקרה, התוצאה נשמרת כ-`words.json` בתיקיית העבודה, במבנה הזה:

```json
{ "words": [ { "w": "שלום", "startSec": 0.4, "endSec": 0.8 } ] }
```

**אם יש לכם VTT או SRT, בקשו ממני להמיר, זו פעולה של שנייה.**

---

## שלב 2. לבחור את הרגעים. זה החלק שאתם עושים

**אני קורא את התמליל ומציע חמישה רגעים** עם זמן התחלה, זמן סיום וכותרת.
אתם מאשרים או מחליפים.

🔴 **ומה שאני בודק לפני שאני מציע, וכדאי שתדעו שזה קורה:** הקלטה של
וובינר **מלאה בשמות של משתתפים**. ״תודה רונית״, ״גולן שאל״, מספר טלפון
שמישהו הכתיב. **הקטעים האלה יוצאים לרשת בשם שלכם.** לכן אני ממפה את כל
אזכורי השמות בהקלטה, ומציע רק חלונות נקיים.

**ההחלטה נשמרת ב-`clips.json`:**

```json
{
  "source": "webinar.mp4",
  "approved": false,
  "clips": [
    { "startSec": 465, "endSec": 520, "title": "ההבטחה שנתתי לעצמי" }
  ]
}
```

🔴 **בלי `"approved": true` הסקריפט מסרב לרוץ.** זה לא נימוס, זו נעילה:
קטע שיצא לרשת עם שם של לקוח לא חוזר.

## שלב 3. לחתוך

```
node scripts/make-clips.mjs .
```

והקטעים יוצאים ב-`clips/`, כל אחד 1080x1920 עם כתוביות שרופות.

---

## הקלטה עם שיתוף מסך: שני שדות שמשנים הכל

רוב הוובינרים הם **שקף גדול ובפינה ריבוע קטן של הדובר**. בלי טיפול, הקטע
האנכי יוצא רצועה אחת שבה הדובר בגודל בול והשקף לא קריא.

**שני שדות ב-`clips.json` מפרקים את המקור ומרכיבים אותו מחדש:**

```json
"speakerCrop": "293:170:987:28",
"slideCrop":   "987:555:0:100"
```

הפורמט הוא `רוחב:גובה:x:y` בפיקסלים של המקור. **הדובר עולה למעלה בגודל
מלא, והשקף יושב מתחתיו.** בלי שני השדות האלה הכלי משתמש בפריסת ברירת
המחדל, שמתאימה להקלטת מצלמה רגילה.

**איך יודעים את המספרים:** מוציאים פריים אחד ומודדים עליו. בקשו ממני,
אני עושה את זה בשתי פקודות.

## תיקוני תמלול

מנוע תמלול שומע ״נכדים״ ככ״מנחדים״ ו״תלות״ כ״בוטלות״. **כתובית עם שגיאה
כזאת גורמת לצופה לחשוב שאמרתם את זה.**

```json
"fixes": { "מנחדים": "נכדים", "בוטלות": "תלות" }
```

ההחלפה היא על הכתובית בלבד. **הקול לא נוגע.**

## תקלות, ומה הן אומרות

**״clips.json לא אושר״** — עוד לא אמרתם כן. השער עובד.

**כתוביות שיוצאות ריבועים** — הגופן שנבחר לא מכיל עברית.
`CLIP_FONT="Arial Hebrew" node scripts/make-clips.mjs .`

**״לא נמצא ffmpeg״** — `brew install ffmpeg` במק.

**קטע ארוך מ-90 שניות** — אזהרה ולא חסימה. אינסטגרם יחתוך אותו.
