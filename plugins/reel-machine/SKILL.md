# reel-machine

הופך סרטון גולמי מהטלפון לריל מוכן לפרסום: כתוביות שנצרבות לתוך הווידאו, ותמונת שער עם המשפט החזק במרכז.

**מה צריך על המחשב:** `node` וגם `ffmpeg`. זה הכל. אין התקנות כבדות ואין דפדפן ברקע.

## מה לעשות כשמישהו מבקש עזרה

### שלב 1. לוודא ש-ffmpeg קיים

```
ffmpeg -version
```

אם זה נכשל, אמור לו להתקין:
- מק: `brew install ffmpeg`
- חלונות: `winget install ffmpeg`

### שלב 2. להשיג תמלול עם זמנים

הסקריפטים כאן מצפים לקובץ `words.json` במבנה הזה:

```json
{ "words": [ { "w": "שלום", "startSec": 0.10, "endSec": 0.42 } ] }
```

**המשתמש מביא את התמלול, והסקיל לא מתמלל בשבילו.** זו החלטה מכוונת: תמלול דורש חשבון או הורדת מודל, ואנחנו לא רוצים לחייב אותו בכלי מסוים או להוציא לו כסף בלי שביקש.

אם הוא שואל איך, שתי דרכים:
1. **מקומי וחינם:** `pip install openai-whisper`, ואז `whisper video.mp4 --language he --output_format json`. הפעם הראשונה מורידה מודל, אז היא איטית.
2. **כל שירות תמלול** שמחזיר זמנים לכל מילה.

אם המבנה שחזר שונה, **המר אותו למבנה שלמעלה** לפני שאתה ממשיך. אל תשנה את הסקריפטים.

### שלב 3. לתקן מילים שנשמעו לא נכון

תמלול בעברית תמיד טועה בכמה מילים. **פתח את `words.json` ותקן** לפני שצורבים, כי מילה שגויה בדיבור עוברת ובכתובית על המסך היא נראית כמו רשלנות.

### שלב 4. לצרוב כתוביות

```
node scripts/captions.mjs --video raw.mp4 --words words.json --out reel.mp4 \
  --font "Arial Hebrew" --keyword "מדריך"
```

- `--y 0.5` איפה יושבת הכתובית. 0.5 הוא אמצע המסך, מתחת לבי-רול ומעל הפנים
- `--keyword` מילה שתיצבע בכתום. אפשר לחזור על הדגל כמה פעמים
- **מספרים נצבעים לבד**, תמיד
- `--font` שם גופן שקיים על המחשב. במק `Arial Hebrew`, בחלונות `Arial`

### שלב 5. תמונת שער

```
node scripts/cover.mjs --video reel.mp4 --at 3.5 \
  --hook "עם {לייקים} לא הולכים למכולת" --sub "מה כן מביא לקוחות" \
  --out cover.png --font "Arial Hebrew"
```

- `{סוגריים}` צובעים את המילה בכתום
- **המשפט יושב במרכז התמונה**, כי בגריד העין נופלת לאמצע וכותרת בראש נקראת כקישוט
- `--at` שנייה שממנה נלקח הפריים. **בחר רגע שהפנים פתוחות ולא באמצע מצמוץ**
- `--shift 0.14` מזיז את התמונה למטה כדי שהפנים ינחתו מתחת לכיתוב

## דברים ששווה לומר למשתמש

- **כתובית לא יושבת על הפנים.** אם הסרטון מפוצל, על קו התפר. אם מלא, מתחת לסנטר
- **עד שש מילים בכרטיס.** יותר מזה לא מספיקים לקרוא
- **מילה אחת מודגשת בכרטיס**, לא שלוש. אם הכל מודגש, כלום לא
- **תסתכל על התוצאה לפני שמפרסמים.** תמיד

## מגבלות, בגלוי

- עברית נבדקה. שפות אחרות מימין לשמאל לא נבדקו
- הכתוביות נצרבות לתוך הווידאו ולא ניתנות לכיבוי
- אם הגופן לא קיים על המחשב, libass ייפול לגופן ברירת מחדל והתוצאה תיראה אחרת
